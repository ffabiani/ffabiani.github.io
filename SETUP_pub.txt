# Publications page (generated from the CV)

The Publications page is built from the lists in assets/files/CV_FF.pdf.

Files involved
- assets/files/CV_FF.pdf        the source of truth
- scripts/update_publications.py  reads the PDF and writes the data file (optional helper)
- _data/publications_cv.yml     generated data: preprints, journal, conference
- _pages/publications.md        renders the three lists
- assets/css/publications.css   styling (unchanged)

Display
- Sections: Preprints, Journal papers, Conference papers.
- Order and wording follow the CV (newest first).
- Labels count down automatically: [P6]...[P1], [J31]...[J1], [C31]...[C1].
- F. Fabiani is bold. Titles link only where the CV gives a link (currently the arXiv paper P1).

Updating after a new CV
1. Replace assets/files/CV_FF.pdf.
2. From the repository root run:  python3 scripts/update_publications.py
   (needs pdftotext from poppler, and PyYAML; on macOS: brew install poppler; pip3 install pyyaml)
3. Check the diff of _data/publications_cv.yml, commit and push.

The script stops with an error if the CV numbering is not consecutive or an entry cannot be parsed.
You can also edit _data/publications_cv.yml by hand; each entry has authors, title, venue and an optional url.
Keep entries newest first, as the labels are assigned from the top of each list.
