The course introduces the analysis and control of dynamical systems, covering controller design, estimation and state reconstruction. Starting from classical mathematical methods, it explores how data and machine learning can be used to address these problems, discussing the strengths and limitations of each approach. Lectures are complemented by practical programming sessions using MATLAB, Python or Julia.

For the full course information, see the [University of Florence course catalogue](https://unifi.coursecatalogue.cineca.it/corsi/2026/4474/insegnamenti/2026/65854_B335-26-26_101251_830977/2026/65854?coorte=2026).
