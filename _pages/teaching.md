## MSc teaching

### Optimization and Machine Learning for Dynamical Systems (University of Florence)


This course aims at introducing classical problems in systems-and-control theory, such as the analysis of dynamical systems and the associated controller synthesis, estimation and state reconstruction problems. Starting from classical mathematical methods, it explores how data and machine learning can be used to address these problems, discussing the strengths and limitations of each approach. Frontal lectures are complemented by hands-on sessions involving programming in MATLAB, Python, or Julia.


#### Learning outcomes

**Prerequisites:** linear algebra, mathematical analysis and calculus.

The course covers three main areas:

1. **System theory**
    - State-space representations for modelling linear systems.
    - Structural properties: stability, controllability and observability.
    - Basic state-feedback controller design through pole placement.
    - Linear state-observer design (Luenberger observers).
    - The separation principle for dynamic compensator design.
2. **Optimization and optimal control**
    - Fundamentals of optimization, with a focus on convex problems.
    - Optimization-based control design: model predictive control (MPC) and the linear quadratic regulator (LQR).
3. **Machine learning for dynamical systems**
    - Neural networks for system identification and control.
    - Kernel-based methods.
    - Data compression and dimensionality reduction.

**Video lectures:** *Data-driven Control with Machine Learning* on YouTube, by Prof. Brunton (University of Washington).

#### Assessment

Assessment consists of either a **standard oral exam** or a **final project discussion**. Exam dates are listed in the official exam calendar.

Projects can be completed **individually or in pairs**. The project report should cover:

1. A continuous- or discrete-time system model.
2. Linearization and a discussion of the system's structural properties.
3. Implementation of a machine-learning-based or data-driven system identification technique.
4. Controller design.
5. Numerical simulations using MATLAB, Python, Julia or similar tools.

**Submission:** email both the **report and code** to [filippo.fabiani@unifi.it](mailto:filippo.fabiani@unifi.it) **three days before the exam**.
